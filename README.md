# ☁️ Capstone Project – Weather Forecasting Public App (Beta)

## 📄 Description
This is a Capstone Project focused on developing a public web application that provides real-time weather updates using a Weather API. The application displays weather conditions such as temperature, rain, and forecasts in a clean and responsive interface.

Currently in **Beta**, the app is under active development and may not include all features or final UI design.

## 🚧 Status
🔧 Beta Version – Work in Progress  
🗓️ More features and improvements coming soon!

## 🌐 Features (Planned & In Progress)
- Live weather data from external Weather API  
- Display of rain conditions, temperature, and city-based forecasts  
- Responsive and user-friendly design  
- Location-based weather detection (Planned)  
- Dark mode (Planned)

## 🛠️ Technologies
- **Frontend:** HTML, CSS, JavaScript  
- **API:** Weather API (e.g., OpenWeatherMap)  
- **Version Control:** Git & GitHub
